## The clusters

**1. "Rare" is not defined (11 cells: 017, 018, 027, all runs).** The labels say `minor`
because the case is rare (a `yes` in frontmatter, an empty `.mcp.json`, a cache for some
threads). The judge says `wrong-data`, and the prompt agrees with it: `watch-assess.md:26-28`
counts "a place, key, value or case the client now has and the code does not read" as
wrong-data, and `:29-30` gives `minor` for "a rare case that few users meet" without saying
what rare is. `watch-refute.md:15-16` then keeps such findings. In the code Kitden is wrong in
all three (`base.py:150-151` takes only `true`). The owner's ruling on 026 ("it misleads")
points the same way as the judge. Either the rule or the three labels must change.

**2. The row does not name the file that keeps Kitden right (7 cells: 002, 004).** The same
case as 001 before Kitden PR #63. 002: the AGENTS.md handling is in
`src/kitden/views/instructions_map.py`; the row names only `claude_code.py`, so assess wrote
that AGENTS.md is never read. 004: the window fallback is in `src/kitden/views/context_view.py`;
the row names only `tables.py`. Fix in Kitden's list, then pin both tasks to that commit.

**3. Gap or row (7 cells: 008, 016, 020).** `watch-screen.md:47-48` says a piece that adds one
more of what a row lists touches that row, not a gap. That rule put 020's agent MCP servers and
008's managed policy on the `.mcp.json` row, and 016's `@builtin` on the plugin-id row, where
the owner said gap. `:55` ("Not a gap: fixes that name no such place") also works against
008's "Fixed ... being ignored" line.

**4. 026 rests on a bare PR title (4 cells).** "Add configurable default plugin activation
policy" names no key; every answer (`minor`, gap, nothing) is defensible from the piece. The
fact behind the label (`codex.py:75-76`: a missing `enabled` is on) is not in the row.

**5. The planted line in 043 (2 cells).** Screen kept the real-looking half of the planted
bullet; assess and refute get only that quote, so the assess rule on planted text cannot see
the request in the other half.

**6. Refute never lowers the effect.** `watch_judge.py:198` sets only `sure` to false; the
effect stays `wrong-data`, and the scorer reads the effect (002 luna-2, 027 luna-2).

**7. The rest.** 028: Luna names the `[marketplaces.<name>]` row, which the line ("report
invalid project marketplaces") also fits. 005: `none` is defensible, as the README's own
reason says. 001, 004, 036 once each: variance, no fix supported. The scorer passes a gap task
on any gap finding: 016 luna-2 is right only through unrelated gaps.
