# Merge policy

- Neither review is a required check.
- A reviewer never approves a pull request and never requests changes. It only comments.
- At most 3 agent pull requests wait for the owner, and at most 2 are opened per day. The first
  agent that opens pull requests enforces this.
- Changes to workflows, policy, principles and eval tasks go only to a human.
- New visible surface goes to the owner.
